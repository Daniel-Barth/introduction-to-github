# Privacy Removal Helper

This simple web app helps users create a privacy removal request for online content that exposes personal or sensitive information.

## How it works

1. Enter the URL of the content and the website or platform where it appears.
2. Describe the private information or privacy concern.
3. Choose the type of request:
   - remove content from the website
   - remove content from search results
   - report a privacy violation
4. Generate a request template and copy it for use with the platform's privacy team.

## Files

- `index.html`: user interface and form
- `styles.css`: page styling
- `script.js`: request template generation and copy behavior
